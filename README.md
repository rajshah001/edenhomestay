# Eden's Homestay — Your Home in the Valley 🏔️

Portfolio website for **Eden's Homestay**, Chongay Tar, Gangtok, Sikkim — a family-run homestay above the town with mountain & valley views, local organic food, and free parking.

**Book / enquire:** [Airbnb](https://www.airbnb.com/h/edenshomestay) · [Booking.com](https://www.booking.com/hotel/in/edens-homestay.html) · [Agoda](https://www.agoda.com/en-in/eden-s-homestay/hotel/gangtok-in.html) · Instagram [@edenshomestaysikkim](https://www.instagram.com/edenshomestaysikkim/) · WhatsApp **+91 90648 10826**

## ✨ Highlights

- Living 3D hero: your photo of the valley, drifting mist, falling cherry petals, crossing birds
- Authentic Tibetan **lungta prayer flags** — wind horse, Om Mani Padme Hum & Tashi Delek in Tibetan script, waving in cursor-driven wind
- "Postcard from Eden" WhatsApp widget with an availability composer (dates, guests, room → pre-filled WhatsApp message)
- Hand-illustrated room cards, radial attraction-distance map, review gauges, house rules, OpenStreetMap embed
- Fully responsive, zero build step, `prefers-reduced-motion` friendly

## 🛠 Stack

Plain HTML + CSS + JS. No frameworks, no build step.

## 🚀 Run locally

```bash
python3 -m http.server 8123
# open http://localhost:8123
```

## ⚙️ Config

Set the WhatsApp number in `script.js` (`WHATSAPP_NUMBER`), already wired to **919064810826**.
